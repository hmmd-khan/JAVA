# JAVA-OOP-LAB-1-HAMMAD-KHAN
# Lab 01 – Thinking in Objects

## Course
Object-Oriented Programming (OOP)

## Laboratory
Lab 01 – Thinking in Objects

## Objective

This laboratory introduces the basic concepts of Object-Oriented Programming (OOP) using Java. The aim is to model real-world objects as Java classes, implement their behaviour, and understand object creation, constructors, UML class diagrams, and Java memory representation (Stack and Heap).
