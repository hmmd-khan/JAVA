Welcome to my **Object-Oriented Programming (OOP)** repository! This repository serves as a practical archive for my implementation of core OOP principles, software design concepts, and coding exercises.

## 📌 Repository Overview

The goal of this repository is to demonstrate a clear, hands-on understanding of Object-Oriented Programming paradigms through well-structured code examples and practical scenarios.

### 🎯 Key Concepts Covered

1. **The 4 Pillars of OOP**
   - **Encapsulation**: Hiding internal details and protecting object state using access modifiers, getters, and setters.
   - **Abstraction**: Hiding implementation complexity and exposing only essential interfaces to the user.
   - **Inheritance**: Reusing code and establishing hierarchical relationships between parent and child classes.
   - **Polymorphism**: Enabling objects to take on multiple forms through *Method Overriding* (runtime polymorphism) and *Method Overloading* (compile-time polymorphism).

2. **Object Relationships**
   - **Aggregation**: Modeling "Has-A" relationships where child objects can exist independently of the parent container (weak coupling).
   - **Composition**: Modeling "Has-A" relationships where child object lifecycles are strictly tied to the parent object (strong coupling).

3. **Interfaces & Contracts**
   - Defining behavioral contracts using **Interfaces**.
   - Achieving loose coupling, multiple inheritance (where applicable), and polymorphic substitution.
